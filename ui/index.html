接口说明（供 WorkBuddy 调用）

取待识别回信　GET /api/ai/tasks?limit=20
返回正文前 4000 字、链接清单、来源账号与命中引用。

写回判定　POST /api/ai/result
单条 {reply_id, category}；批量 {items:[...]}。
category 取 A（有意向报价）/ B（有回复未报价）/ C（疑似拒绝）。

看板聚合　GET /api/dashboard　账号详情 GET /api/account_detail?email=
任务控制　POST /api/campaign {state:running|paused|idle}
断点续发　POST /api/resume　立即收信　POST /api/poll
任务进度　GET /api/progress　未确认邮件　GET /api/unknown　POST {id, action:sent|retry}
